报告测试结果

工作方式

这份清单只回答一个问题：这款软件能否在 RTX Spark 笔记本上运行？每条结果都附有来源或标明日期的测试报告。

结果的含义

原生
有 Windows Arm64 版本，直接在芯片上运行。
Prism 可运行
只有 x64 或 x86 版本，通过 Microsoft Prism 模拟运行。
Prism 无法运行
x64 或 x86 版本在 Prism 下无法启动或无法正常使用。

结果的来源

每条数据首先依据原厂文档、发布页面或评测，并标明来源是实测 RTX Spark，还是 Windows on Arm 的通用信息。通用信息是重要参考，但不等于保证，因为 GPU 驱动、插件和反作弊系统的行为可能不同。

其他数据库

列表里也列出 Linaro Works on WoA 目录和 winget 的 Arm64 软件包，每天自动更新。本站没有逐条核实，所以标为“未核实”。NVIDIA 为 Linaro 验证过的软件按 NVIDIA 的结果标为“NVIDIA 验证”，Linaro 其余的结果大多在 Qualcomm 硬件上测试。winget 出现 Arm64 软件包时，会取代较旧的模拟结果，因为有 Arm64 版本就是这里所说的原生。

报告如何审核

报告发送后即公开。每天的审核会确认报告完整且合理，然后决定接受或退回。社区报告不会直接覆盖有来源的结果，两者不一致时，软件页面会明确标示。

每天做什么

每天搜索网络和 GitHub，寻找新的 Arm64 版本和社区移植，例如 vLLM 的 RTX Spark 社区版。新条目必须附上来源链接，每一行的日期就是最后核实日期。
