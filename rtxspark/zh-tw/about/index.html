回報測試結果

運作方式

這份清單只回答一個問題：這套軟體能不能在 RTX Spark 筆電上跑？每筆結果都附上來源或標明日期的測試回報。

結果代表什麼

原生
有 Windows Arm64 版本，直接在晶片上執行。
Prism 可執行
只有 x64 或 x86 版本，透過 Microsoft Prism 模擬執行。
Prism 無法執行
x64 或 x86 版本在 Prism 下無法啟動或無法正常使用。

結果從哪裡來

每筆資料先以原廠文件、發行頁面或評測為依據，並標明來源是實測 RTX Spark，還是 Windows on Arm 的通用資訊。通用資訊可以當作重要參考，但不等於保證，因為 GPU 驅動程式、外掛和反作弊系統的行為可能不同。

其他資料庫

搜尋範圍還包含 Linaro Works on WoA 目錄和 winget 的 Arm64 套件，每天自動更新。本站沒有逐筆查證。NVIDIA 為 Linaro 驗證過的軟體會照 NVIDIA 的結果列在主清單，Linaro 其餘的結果大多在 Qualcomm 硬體上測試。winget 出現 Arm64 套件時，會取代較舊的模擬結果，因為有 Arm64 版本就是這裡所說的原生。
