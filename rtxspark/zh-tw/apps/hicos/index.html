HiCOS 自然人憑證跨平台網頁元件

Prism 可執行

只有 x64 或 x86 版本，透過 Microsoft Prism 模擬執行。

Windows on Arm 來源，尚未在 RTX Spark 確認

自然人憑證的 HiCOS 元件在 Snapdragon X 筆電上可以安裝並讀卡，這是網友實測的結果。

已知限制

  • 官方只提供一個 Windows 安裝檔，沒有提到 Arm 版，所以列為透過 Prism 執行。實測用的是較舊的版本和 Snapdragon X 筆電，不是 RTX Spark。需要 USB 晶片讀卡機，大多數不用另裝驅動程式。
  • 官方下載頁要先通過真人驗證，版本號是從 HiNet 鏡像頁讀到的。
