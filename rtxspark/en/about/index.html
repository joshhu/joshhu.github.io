How it works

This catalog answers one question: will a program run on an RTX Spark laptop? Every result links to a source or a dated test report.

What the results mean

Native
A Windows Arm64 build exists and runs directly on the chip.
Runs under Prism
Only an x64 or x86 build exists, and it runs through Microsoft Prism emulation.
Fails under Prism
The x64 or x86 build does not start or is unusable under Prism.

Where results come from

Each entry starts from vendor documentation, release pages, or reviews. Entries also state whether the source tested RTX Spark itself or Windows on Arm in general. A general result is a strong hint and not proof, because GPU drivers, plug-ins, and anti-cheat can behave differently.

Other catalogs

The list also holds thousands of programs from Linaro's Works on WoA catalog and from winget's Arm64 packages, refreshed daily and marked unchecked, because this site has not checked them one by one. Programs that NVIDIA verified for Linaro show NVIDIA's result and are marked so. The rest of Linaro's results were mostly tested on Qualcomm hardware. A winget Arm64 package replaces an older emulated result, because an Arm64 build is what native means here.

How reports are reviewed

Reports are public from the moment they are sent. A daily review checks that each report is complete and plausible, then accepts or declines it. Community reports never overwrite a sourced result. When they disagree, the software page says so.

What happens every day

Every day we search the web and GitHub for new Arm64 releases and community ports, such as RTX Spark builds of vLLM. New entries need a source link. The date on each row shows when it was last checked.
