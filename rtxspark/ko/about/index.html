운영 방식

이 목록은 한 가지 질문에 답합니다. 이 프로그램이 RTX Spark 노트북에서 돌아갈까요? 모든 결과에는 출처나 날짜가 있는 테스트 보고가 붙습니다.

결과의 의미

네이티브
Windows Arm64 버전이 있어 칩에서 직접 실행됩니다.
Prism에서 실행
x64 또는 x86 버전만 있으며 Microsoft Prism 에뮬레이션으로 실행됩니다.
Prism에서 실행 불가
x64 또는 x86 버전이 Prism에서 시작되지 않거나 제대로 쓸 수 없습니다.

결과의 출처

각 항목은 제조사 문서, 릴리스 페이지, 리뷰를 바탕으로 하며, RTX Spark 실측인지 Windows on Arm 일반 정보인지 표시합니다. 일반 정보는 유력한 단서이지만 GPU 드라이버, 플러그인, 안티치트 동작이 다를 수 있어 보장은 아닙니다.

다른 카탈로그

검색 범위에는 Linaro Works on WoA 카탈로그와 winget의 Arm64 패키지도 포함되며 매일 자동으로 갱신됩니다. 이 사이트에서 하나하나 확인하지는 않았습니다. NVIDIA가 Linaro를 위해 검증한 프로그램은 NVIDIA의 결과 그대로 기본 목록에 싣습니다. Linaro의 나머지 결과는 대부분 Qualcomm 하드웨어에서 테스트되었습니다. winget에 Arm64 패키지가 나오면 오래된 에뮬레이션 결과를 대체합니다. Arm64 빌드가 있는 것이 여기서 말하는 네이티브이기 때문입니다.

Linaro Works on WoA (MIT), winget-pkgs (MIT)
